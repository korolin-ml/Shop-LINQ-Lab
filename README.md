Проект представляет собой адаптацию учебного шаблона под Интернет-магазин. В качестве СУБД используется встроенная SQLite. Связи между таблицами настроены через Entity Framework Core, выборка данных реализована с помощью запросов LINQ.


## Архитектура и структура проекта

```text
UniversityLinqTemplate/
│
├── Models/                 # Слой сущностей (Таблицы БД)
│   ├── Group.cs               # Группы студентов
```

## Структура базы данных

В папке Models реализованы следующие сущности:
1. Customer.cs (Покупатели) — содержит ФИО, электронную почту и город. Связан с таблицей заказов отношением один ко многим.
2. Product.cs (Товары) — содержит наименование, категорию, цену и количество на складе.
3. Order.cs (Заказы) — содержит дату оформления, статус и внешний ключ CustomerId.
4. OrderItem.cs (Позиции заказа) — промежуточная таблица связи многие ко многим между Заказами и Товарами. Фиксирует количество и цену товара на момент покупки.



## Реализованные запросы LINQ

В файле Queries/LinqDemos.cs написаны запросы под обязательные критерии работы:
1. Фильтрация (Where) с использованием логического оператора И. Выбирает электронику дороже 15 000 рублей.
2. Сортировка (OrderBy, ThenByDescending). Сортирует товары по категориям, а внутри них по убыванию цены.
3. Проекция (Select). Извлекает данные в анонимный тип, выбирая только имена покупателей и города.
4. Агрегация (Count, Max, Average). Считает общее число товаров, макс цену и ср стоимость.
5. Группировка (GroupBy). Группирует товары по категориям с подсчетом количества позиций и минимальной цены.
6. загрузка (Include, ThenInclude). Запрос извлекает всю цепочку связанных данных за один цикл.
